# Density-Perturbed Extended Hubbard Dimer Chain

## Model

This is the current best candidate for the paper example.

```text
H(theta) = H0 + theta V

H0 =
  sum over strong dimer bonds (2k-1, 2k)
    -td sum_sigma (c_{2k-1,sigma}^dag c_{2k,sigma} + h.c.)
  + U sum_i n_{i,up} n_{i,down}

V =
  sum over weak inter-dimer bonds (2k, 2k+1)
    n_{2k} n_{2k+1}

selected moments =
  dimer bond kinetic moments
  sum_sigma (c_{2k-1,sigma}^dag c_{2k,sigma} + h.c.)
```

This is an extended spinful Hubbard dimer chain near the isolated-dimer limit.

## Why Density Perturbation Avoids the Hopping Cancellation

For the standard weak-hopping perturbation, the perturbation changes the
particle number on neighboring dimers at first order. Dimer-local
number-conserving observables therefore have a first-order selection-rule
cancellation.

The density-density perturbation is different. It preserves each dimer's
particle number and acts inside the same dimer particle-number sectors. Thus
the selection rule that killed the weak-hopping first-order signal no longer
applies.

Numerically, this is exactly what we see: dimer-local bond kinetic moments have
a robust linear mismatch in norm.

## Leading-Coefficient Observation

The component-wise mismatch is essentially the same sign for positive and
negative theta. Thus the norm lower bound is very clean:

```text
||delta m_S(theta)|| >= c |theta|
```

but the selected SDP optimizer appears to move with an absolute-value cusp in
theta rather than a smooth signed derivative. This is visible in
`density_hubbard_L4_U4_bond_mosek_delta_components.csv`: each component has
`|delta_i / theta|` near `0.088`, giving a vector norm near `0.125`.

This is enough for the numerical lower-bound check, but it is a caveat for any
argument that requires a globally `C1` choice of the unpinned SDP optimizer in
theta. If the paper needs that stronger regularity, we should add a
tie-breaking rule or explicitly formulate the example around the norm lower
bound rather than a signed derivative.

## Current Interpretation

This model is currently the strongest paper example:

1. it is spinful and interacting;
2. the isolated-dimer reference is exactly controllable;
3. the selected moments are physical bond kinetic observables;
4. MOSEK gives clean reference exactness;
5. the mismatch lower bound is robust and persists from `L=4` to `L=6`.

The remaining technical point is not the lower bound itself, but how to phrase
the optimizer regularity around the reference point.
