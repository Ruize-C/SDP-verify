# Standard Dimerized Spinful Hubbard Chain

## Model

This is the canonical weakly coupled / dimerized spinful Hubbard chain.

```text
H(theta) = H0 + theta V

H0 =
  sum over strong dimer bonds (2k-1, 2k)
    -td sum_sigma (c_{2k-1,sigma}^dag c_{2k,sigma} + h.c.)
  + U sum_i n_{i,up} n_{i,down}

V =
  - sum over weak inter-dimer bonds (2k, 2k+1)
      sum_sigma (c_{2k,sigma}^dag c_{2k+1,sigma} + h.c.)
```

Equivalently, the physical hopping amplitudes are alternating:

```text
t_strong = td,
t_weak   = theta.
```

The reference point `theta = 0` is a product of two-site Hubbard dimers.

## Moment Scan With MOSEK

Generated by `scripts/scan_standard_moments_mosek.jl`.

The scan used `L = 4`, `U = 2`, `theta = +/-0.005, +/-0.01`.
It tested dimer-local and inter-dimer selected moments.

Main observations:

- dimer-local moments satisfy reference exactness and response matching, but
  their mismatch is quadratic: the ratio
  `(|theta| = 0.005) / (|theta| = 0.01)` is about `0.5`;
- inter-bond kinetic has a strong linear mismatch signal, with
  `||delta m||/|theta|` about `4.59`, but it fails response matching badly
  (`response_diff_norm` about `7.05`);
- inter-density also fails response matching badly.

So the current standard model has a tradeoff: the physically tempting
inter-bond moments give a first-order mismatch but violate
Assumption `ref-match`, while the moments that pass `ref-match` only give
second-order mismatch under weak hopping.

## Dimer-Local Moment Search

Generated by `scripts/scan_standard_dimer_local_moments_mosek.jl`.

This scan focuses only on observables supported on the strong Hubbard dimers.
It added:

- dimer spin-z correlation;
- dimer spin exchange;
- dimer spin dot product;
- dimer pair hopping;
- singlet projector;
- triplet-zero projector.

All these dimer-local candidates preserve the clean reference behavior:
reference energy errors are about `1.46e-9`, and response-matching errors are
between about `1e-10` and `1e-6`.

However, none gave a robust first-order mismatch. The relevant stability ratio

```text
(||delta m||/|theta| at |theta|=0.005)
/
(||delta m||/|theta| at |theta|=0.010)
```

is close to `0.5` for the meaningful-signal observables:

```text
dimer_spin_exchange       stability about 0.505
dimer_spin_dot            stability about 0.505
dimer_singlet_projector   stability about 0.505
dimer_pair_hopping        stability about 0.499
double_occupancy          stability about 0.504
bond_kinetic              stability about 0.511
```

This is the numerical signature of quadratic scaling. The triplet-zero
projector has a slightly larger stability ratio, about `0.592`, but its signal
is tiny: `||delta m||/|theta|` is only about `1.2e-4` at `|theta|=0.01`, so it
is not a credible linear-mismatch candidate.

## Interpretation

The canonical alternating-hopping spinful Hubbard chain satisfies the intended
model class and the isolated-dimer reference is numerically exact. With MOSEK,
the reference exactness and response-matching checks are clean for dimer-local
moments.

However, for all dimer-local moments tested so far, the mismatch under weak
inter-dimer hopping appears to be quadratic in `theta`, not linear. These
moments therefore do not verify the lower bound
`||delta m_S(theta)|| >= c |theta|`.

The extended density-perturbed Hubbard dimer example remains numerically
cleaner for the linear mismatch requirement. The standard hopping model is more
canonical physically, but it needs either a different selected moment set or a
modified perturbation/reference setup to satisfy all three requirements at
first order.

Before using this as the main paper example, the next step should be either:

- investigate whether the first-order cancellation for dimer-local observables
  can be proved from the isolated-dimer product structure and number
  conservation;
- try a modified standard setup, such as adding a small staggered onsite
  potential to break the symmetry responsible for the cancellation;
- or present the standard hopping model as a canonical comparison where the
  tested moments only produce a quadratic mismatch, while using the
  density-perturbed extended Hubbard dimer as the main linear-mismatch example.

See `reports/cancellation_and_staggered_report.md` for the follow-up. The
staggered onsite potential increases the quadratic coefficient but does not
produce a first-order mismatch, consistent with the dimer particle-number
selection-rule explanation.
